# Jana Unified Platform

Клиенттік **Jana AI Chat** және операторлық **SWAT** жүйесінің функционалды браузерлік прототипі.

## Прототипте жұмыс істейтін функциялар

- JPID арқылы демо-кіру: клиент үшін кез келген JPID; операторлық режим үшін `SWAT`, `OPERATOR`; `SUPERVISOR` және `ADMIN` — демо рөлдері.
- Клиенттің жеке өтініштер тізімі: аяқталмаған және аяқталған мәселелер.
- Трек-кодпен жаңа тикет ашу және тикетке JPID-ді байланыстыру.
- SWAT-та 7 бағанды Kanban тақтасы, тикетті сүйреп басқа бағанға ауыстыру.
- Тикет карточкасы: Клиент, Информация, История қойындылары.
- 13 кезеңдік прогресс және мәртебені өзгерту.
- Клиент JPID өрісін редакциялау.
- Клиент пен оператор арасында екі бағытта хабарлама жазу, хабарламаны өңдеу.
- Хабарламадан іздеу, emoji, файл тіркеу және Ctrl+V арқылы сурет қою.
- Тикет тарихына негізгі өзгерістерді тіркеу.
- Бір браузердегі localStorage және ашық қойындылар арасындағы синхрондау.

## Жергілікті іске қосу

```bash
npm install
npm run dev
```

## Деректер және прототип шектеулері

Бұл — GitHub Pages-та ашылатын статикалық браузерлік прототип. Тикеттер мен хабарламалар браузердің localStorage қоймасында сақталады; бір браузердегі ашық қойындылар арасында синхрондалады. Әртүрлі құрылғылар/қолданушылар арасында ортақ серверлік дерекқор мен нақты уақыттағы чат әлі қосылған жоқ.

Supabase жобасы қосылған кезде `supabase/schema.sql` бастапқы кестелерді құрады. Cloud режимін қосу үшін GitHub Actions secrets ішінде `VITE_SUPABASE_URL` және `VITE_SUPABASE_ANON_KEY` мәндерін орнату жеткіліксіз: клиент кодына нақты Auth, CRUD, Realtime және RLS интеграциясын қосу қажет. Қазіргі прототип бұл интеграцияны әлі орындамайды.

**Қауіпсіздік:** JPID-тің өзін ғана парольсіз енгізу — тек демонстрациялық кіру. Өндірістік жүйеде расталған аутентификация, рөлдік рұқсаттар және дерекқор деңгейіндегі RLS міндетті.


## Екі портал және ортақ real-time сервер

- Клиент порталы: GitHub Pages сайтының негізгі мекенжайы.
- Оператор порталы: сол домендегі `/operator.html` (SWAT демо режимі).
- Екі портал бір Hatchable API серверіне және PostgreSQL дерекқорына қосылады.
- Hatchable жобасы әдепкіде private: GitHub Pages-тен API-ға қол жеткізу үшін Hatchable Console → Settings → Sharing ішінен жобаның Visibility мәнін **Public** ету қажет.
- Әр өзгерістен кейін сервер `jana-post` арнасына оқиға жариялайды; браузерлер Hatchable Realtime арқылы өзгерісті бірден алып, ортақ күйді қайта жүктейді. Өз қолымызбен polling циклін қолданбаймыз.
- Сервер API: `https://jana-post-realtime.hatchable.site/api/state`; оқиға токені: `/api/events-token`.

**Демо режим:** JPID-only кіру. Hatchable жобасы Public етілмесе немесе API уақытша қолжетімсіз болса, интерфейс осы браузердегі localStorage режиміне автоматты түрде ауысады. Бұл нұсқа тек прототипке арналған; ашық API және рөлдерді тексермеу өндірістік қауіпсіздікке жарамайды.
