# Jana Unified Platform

Бірыңғай клиенттік **Jana AI Chat** және операторлық **SWAT** жүйесінің бастапқы MVP негізі.

## Қазір бар
- JPID арқылы прототиптік кіру (оператор демо-кіруі: `SWAT`).
- Клиенттік өтініштер тізімі және жаңа өтініш ашу.
- SWAT Kanban тақтасы, 7 жұмыс мәртебесі және өтініш карточкасы.
- Бір өтініштің ішіндегі клиент/оператор хабарламалары.
- Бір браузердегі қоймаға сақтау және басқа ашық қойындылармен localStorage синхрондауы.
- Supabase-ке арналған бастапқы дерекқор схемасы.

## Жергілікті іске қосу
```bash
npm install
npm run dev
```

## Cloud database орнату
1. Supabase жобасын ашыңыз.
2. SQL Editor ішіне `supabase/schema.sql` файлын енгізіп орындаңыз.
3. Project URL және anon key мәндерін deployment environment-ке `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` ретінде қосыңыз.
4. Production алдында Authentication және Row Level Security саясаттарын міндетті түрде баптаңыз.

## Маңызды
Қазіргі нұсқа — бастапқы интерфейс және браузерлік demo mode. Cloud database credentials пен қауіпсіз авторизация қосылмайынша, әртүрлі құрылғылар арасында ортақ дерекқор/нақты уақыттағы чат іске қосылды деп есептелмейді. JPID-тің өзін ғана парольсіз қолдану өндірістік ортаға қауіпсіз емес.
